# «Свои» — демо-трекер задач

Портфолио-приложение с канбан-доской для семейных и бытовых задач. Без регистрации: каждому посетителю выдаётся отдельная демо-доска с вымышленными данными.

**Стек:** Next.js, TypeScript, PostgreSQL, Prisma · **Демо-хостинг:** Railway

## Возможности

- Канбан из трёх статусов: «К выполнению», «В работе», «Готово».
- Создание, назначение, редактирование и удаление задач.
- До 10 демонстрационных участников на доске.
- Перетаскивание карточек и управление статусом без drag-and-drop.
- Недельная сводка, история событий и упрощённый доступный вид.
- Отдельная cookie-сессия для каждой демо-доски.

Все имена и задачи в приложении вымышлены. Не вводите реальные персональные или медицинские данные.

## Локальный запуск

Требуются Node.js 20.9+ и Docker с Docker Compose.

```bash
npm ci
cp .env.example .env
docker compose up -d db
npm run db:deploy
npm run dev
```

Откройте `http://localhost:3000`. Остановить локальную базу можно командой `docker compose down`; для удаления локальных данных базы — `docker compose down -v`.

Для разработки схемы используйте `npm run db:migrate`. Вспомогательные команды:

```bash
npm run typecheck
npm run lint
npm run build
npm run db:studio
```

## Публикация на Railway

1. Создайте проект Railway и добавьте сервис PostgreSQL.
2. Подключите GitHub-репозиторий как сервис приложения.
3. Свяжите переменную `DATABASE_URL` приложения с переменной подключения PostgreSQL из Railway.
4. Railway использует настройки из `railway.json`: `npm run build` при сборке, миграции Prisma при старте и health check `/api/health`.
5. После успешного деплоя откройте домен приложения и проверьте создание задачи, переключение статусов, участников и сброс демо.

Локальный `.env` и его значения не коммитьте. На Railway задавайте секреты только в настройках переменных окружения.

## Структура репозитория

- `app/` — страницы, API и серверные действия Next.js.
- `components/` — интерфейс доски и её элементов.
- `lib/` — сессии, запросы, валидация и демонстрационные данные.
- `prisma/` — схема PostgreSQL, миграции и seed-скрипт.
- `Референсы/` — брендбук и дизайн-референсы проекта.
- `TS.md` — техническое задание демо-версии.
